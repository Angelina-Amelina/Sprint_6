# Автоматизация тестирования веб-приложения [Яндекс.Самокат](https://qa-scooter.education-services.ru/)

Проект автоматизированного E2E-тестирования веб-сервиса для заказа самокатов, покрывающий ключевые сценарии платформы, включая проверку выпадающих списков, оформление заказа двумя способами и валидацию редиректов.

🛠️ Технологии:
* **Python 3.10** — основной язык программирования
* **Pytest** — фреймворк для написания, параметризации и запуска тестов
* **Selenium WebDriver** — инструмент для автоматизации действий в браузере
* **WebDriverWait** — встроенный механизм Selenium для реализации динамических явных ожиданий
* **Allure Framework** — инструмент для генерации детальных отчетов

📋 Особенности реализации:
* **Page Object Model (POM)** — архитектура проекта разделена на базовый класс, логику страниц и тест-кейсы для упрощения поддержки кода
* **Разделение локаторов** — все локаторы элементов вынесены в отдельные файлы внутри папки `locators/`
* **Динамические элементы** — взаимодействие со сложными React-элементами (кастомные дропдауны, календарь) реализовано через явные ожидания
* **Динамические отчеты** — заголовки тестов в Allure формируются динамически на основе параметров (номер вопроса, имя покупателя)

📥 Как установить проект:
1. Клонируйте репозиторий с проектом:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd Sprint_6
```
2. Создайте и активируйте виртуальное окружение (venv):
* **Для Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```
* **Для macOS / Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
3. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

🚀 Как запустить проект:
Перед запуском убедитесь, что виртуальное окружение активировано в вашем терминале. Также проверьте корректность пути к `firefox.exe` в фикстуре `driver` внутри `conftest.py`.

* **Запуск всех тестов в проекте:**
  ```bash
  pytest
  ```
* **Запуск тестов с подробным выводом результатов (verbose режим):**
  ```bash
  pytest -v
  ```
* **Запуск конкретного тестового файла:**
  ```bash
  pytest tests/test_order_page.py -v
  ```
* **Запуск определенного класса тестов:**
  ```bash
  pytest tests/test_order_page.py::TestOrderPage -v
  ```

📊 Как сгенерировать Allure-отчет:
Для сборки отчета на компьютере должна быть установлена консольная утилита Allure CLI.

* **Запуск тестов и генерация отчета в один автономный HTML-файл:**
  ```bash
  pytest --alluredir=allure-results --clean-alluredir && allure generate allure-results --single-file -o single-report --clean
  ```
Готовый отчет сохранится в папку `single-report/index.html`. Его можно открывать в любом браузере и пересылать как один файл.
